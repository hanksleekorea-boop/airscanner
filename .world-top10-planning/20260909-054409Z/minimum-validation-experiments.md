# 최소 검증 실험

1. **공급자 정확성**: 같은 서울·2박·2인 조건을 20회 요청해 총액·통화·세금 필드 완전성, p95, stale 비율을 기록한다. 합격은 완전성 100%, 오류 상태 100% 명시다.
2. **클릭아웃 안전성**: 허용/비허용 100개 URL fixture를 실행한다. open redirect 0, `subId` 손실 0, 고지 노출 100%가 합격이다.
3. **부분 장애**: 공급자별 timeout/429/5xx를 주입한다. 부분 결과·재시도·대체 경로가 명확하고 허위 최저가가 0이어야 한다.
4. **접근성**: 키보드만으로 검색→비교→상세→클릭아웃, 스크린리더로 총액·환불·판매처를 수행한다.
5. **모바일 실기기**: ADB에 화면이 꺼진 유휴 폰이 보일 때 한 대만 사용해 QR→PWA 설치→오프라인 셸→재연결을 검증한다. 기기가 없으면 미실행으로 기록한다.
