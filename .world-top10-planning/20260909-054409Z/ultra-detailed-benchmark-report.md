# HotelScanner 세계 톱10 상세 벤치마크

## 판정 요약

24개 동일 항목을 0~5로 채점했다. HotelScanner의 현재 공개판 평균은 **1.833/5**, 고정한 세계 톱10 평균은 **4.292/5**로 산술 격차가 **2.458점**이다. 이 수치는 제품 품질의 절대 순위가 아니라, 공개 증거가 있는 기능 표면을 같은 기준으로 비교한 계획용 기준선이다.

가장 큰 격차는 판매처·요금 범위(0 대 4.7), 지도·위치(0 대 4.3), 예약 클릭아웃·전환(0 대 4.3), 제휴·수익화(0 대 4.2)다. 현재 사이트는 Cloudflare 실행 서버(Worker), 사용자 저장소(D1), 위세이버 OAuth, PWA, 표본 검색과 비교 기능은 확인됐지만 실시간 OTA 공급자는 `WAITING_EXTERNAL`이다. 따라서 샘플 가격을 실판매 가격으로 해석하면 안 된다.

## 상위 서비스에서 가져올 공통 패턴

- Google Hotels는 가격·위치·등급·편의시설 필터와 지도, 파트너 가격, 세금·수수료 정확성 표시를 결합한다. [Google Travel 도움말](https://support.google.com/travel/answer/6276008?hl=en-EN)
- KAYAK·trivago·HotelsCombined·Skyscanner는 다수 판매처를 비교하고 사용자가 판매처로 이동하는 메타서치 흐름을 명확히 한다. [KAYAK Hotels](https://www.kayak.com/hotels), [trivago](https://www.trivago.com/en-US), [HotelsCombined](https://www.hotelscombined.com/about), [Skyscanner Hotels](https://www.skyscanner.com.sg/hotels)
- Tripadvisor는 리뷰가 선택 근거가 되도록 가격 비교와 결합한다. [Tripadvisor Hotels](https://www.tripadvisor.com/Hotels)
- Wego는 지역 공급과 세금 포함 가격을 전면에 둔다. [Wego Hotels](https://www.wego.com/hotels)
- Booking·Agoda·Expedia는 재고 폭, 취소 조건, 회원 혜택과 지원을 강화한 OTA 기준을 제공한다. [Booking.com](https://www.booking.com/), [Agoda](https://www.agoda.com/), [Expedia Hotels](https://www.expedia.com/Hotels)

## 결론

현재 제품은 “신뢰 가능한 비교 UI와 Cloudflare 기반의 무료 표본 MVP”로는 준비됐지만, 톱10과 같은 의미의 실시간 최저가 메타서치로는 아직 아니다. 1단계 상용화의 합격조건은 공급자 한 곳 이상을 계약·키·정책까지 검증하고, 가격 원장·클릭아웃·오류 복구를 증거로 남기는 것이다.
