# 핵심 사용자 여정 정면 비교

| 여정 | 톱10의 기대 동작 | 현재 HotelScanner | 즉시 보강 설계 |
|---|---|---|---|
|검색 시작|목적지 자동완성, 날짜/인원 오류 예방|검증된 입력과 표본 결과|도시/숙소/랜드마크 통합 자동완성, 오류 문구를 입력 옆에 배치|
|가격 확인|판매처별 총액·세금·취소 조건을 같은 카드에서 비교|표본 총액 원장·미확인 비용 경고|공급자 응답을 공통 스키마로 정규화하고 `priceAsOf`·세금 포함 여부 표시|
|위치 결정|지도·거리·주변 명소·지역 필터|지도 없음|지도는 별도 라이선스·비용 검토 후 읽기 전용으로 도입, 실패 시 리스트 유지|
|신뢰 판단|리뷰 수·출처·환불 조건·정확성 정책|기본 설명과 상태 라벨|원문 링크·수집시각·검증 배지·불일치 설명 추가|
|예약 이동|명확한 파트너 CTA와 새 창/복귀 처리|클릭아웃 미개통|제휴 deep link, `subId` 추적, 실패 시 대체 파트너와 문의 안내|
|회원 기록|저장 검색·알림·내보내기·삭제|OAuth·D1·내보내기·삭제|저장 검색과 가격 알림을 동의 기반으로 추가|
|재방문|가격 변화·유사 숙소·유연한 날짜 추천|로컬/계정 기록|알림 실패·만료·철회 상태를 사용자에게 노출|

## 모바일/PC 차이

- 모바일: 한 손 입력, 고정 검색 요약, 카드형 결과, 비교 바텀시트, 저대역폭 재시도.
- PC: 좌측 필터·중앙 결과·우측 상세 또는 지도, 키보드 포커스와 URL 공유.
- 같은 데이터 계약을 사용하되 레이아웃만 바꾼다. 모바일에서 기능을 숨겨 의미가 달라지지 않게 한다.
