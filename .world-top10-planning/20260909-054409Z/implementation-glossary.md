# 구현 용어집

- **HotelOfferV1**: 여러 공급자 결과를 같은 필드로 표현하는 계약.
- **총액 원장**: 기본요금·세금·수수료·환율·수집시각을 함께 기록하는 구조.
- **클릭아웃**: 호텔스캐너가 결제를 수행하지 않고 승인된 판매처로 이동시키는 흐름.
- **deep link**: 특정 숙소/객실로 바로 이동하는 파트너 URL.
- **subId**: 전환을 익명으로 구분하는 제휴 추적값.
- **circuit breaker**: 실패 공급자를 잠시 차단해 전체 검색을 보호하는 장치.
- **stale**: 가격/재고가 정해진 시간보다 오래되어 신뢰 경고가 필요한 상태.
- **PWA**: 브라우저에서 설치 가능한 웹앱.
- **D1**: Cloudflare의 SQL 사용자 저장소.
- **Readiness**: 출시 준비 감사. 외부 엔진 점수가 없으면 증거만 보고한다.
