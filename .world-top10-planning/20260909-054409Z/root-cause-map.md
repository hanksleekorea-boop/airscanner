# 갭의 근본 원인 지도

`외부 계약 부재 → 실시간 데이터 부재 → 가격·재고·세금 신뢰 격차 → 클릭아웃/수익화 불가`가 가장 큰 연쇄다. 이를 UI 작업으로 덮으면 허위 최저가 위험이 생긴다.

두 번째 연쇄는 `지도·리뷰·지역화 정책 미결 → 라이선스/법률 미결 → 운영 개통 지연`이다. 세 번째는 `운영 책임자·SLO 미정 → 공급자 장애 시 복구 불가 → 상용화 신뢰 하락`이다.

내부 기반(Cloudflare Worker, D1, OAuth, PWA, 상태 라벨)은 이미 병목이 아니므로, 다음 개발은 공급자 계약·데이터 계약·전환 정책에 집중해야 한다.
