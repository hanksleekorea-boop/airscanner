# 내장 500개 도메인 스캔·매칭

v3.2 내장 목록의 500개 번호를 범주 후보로 스캔했다. 현재 서비스 화면·기획·공개 URL과 직접 연결되는 주 범주는 **124 호텔 예약**이다. 인접 범주는 **123 단기 숙박**, **126 여행 일정**으로 보조 등록했다.

나머지 497개는 호텔 비교 서비스의 직접 사용자 결과·데이터 계약·운영 책임과 연결되지 않아 경쟁사 선정 범위에서 제외했다. 제외는 시장에 서비스가 없다는 뜻이 아니라, 이번 제품의 적용 가능 분석 우주 밖이라는 뜻이다. 번호를 확인하지 않은 후보 서비스나 시장 순위를 만들어내지 않았다.
