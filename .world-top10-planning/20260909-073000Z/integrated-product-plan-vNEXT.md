# HotelScanner 통합 제품기획 vNEXT

## 제품 약속

“같은 객실 조건의 실제 총액과 환불 조건을 판매처별로 투명하게 비교하고, 사용자가 원하는 판매처로 안전하게 이동한다.” 실시간 공급자가 없을 때는 표본을 실제 가격처럼 표시하지 않는다.

## 단계별 목표

### 1단계 — 상용화 가능한 무료 비교

- 공급자 1곳 이상과 제휴 계약·키·쿼터·정책 확인.
- HotelOfferV1, 총액·세금·환율 원장, 수집시각, 판매처 원문 URL 구현.
- 검색/필터/정렬/상세/비교/클릭아웃/실패 복귀를 모바일·PC에서 완성.
- Google/WeSaver OAuth, D1 저장·내보내기·삭제, 개인정보·쿠키·제휴 고지.
- Cloudflare Worker/D1 로그와 장애 배너, 기본 SLO와 온콜 문서.

### 2단계 — 상용화 1년차 수준

- 공급자 2곳 이상 병합, 가격·재고 불일치 원장, 지도/거리, 리뷰 출처.
- 저장 검색·가격 알림, 유연한 날짜·지역 대안, 다국어·통화.
- 도움말·신고·장애 복구, 접근성/Android/저대역폭 회귀.

### 3단계 — 차별화·확장

- 총액 신뢰 지수, 설명 가능한 추천, 회원 혜택·가격 이력.
- 가이드·콘텐츠·광고는 사용자 작업을 방해하지 않는 위치에만 배치.
- 실데이터 30일 이상 확보 후 가격 예측/개인화 실험. 결제·직접 예약은 별도 승인 없이는 구현하지 않는다.

## 비기능 기준

검색 API p95 2초 목표(공급자 대기시간 제외), 공급자 장애 시 5초 내 명확한 상태, PWA 오프라인 셸, WCAG 2.2 AA 핵심 흐름, 모든 개인정보 삭제·내보내기, B드라이브/Apple 로그인/결제 제외.

## 상용화 게이트

P0 갭이 모두 증거로 PASS이고, 샘플/실시간 문구가 일치하며, 개인정보·제휴 고지와 운영 담당자가 확인된 경우에만 “무료 상용화”로 표현한다. Readiness 엔진 점수가 없으면 점수 대신 증거 목록을 보고한다.
