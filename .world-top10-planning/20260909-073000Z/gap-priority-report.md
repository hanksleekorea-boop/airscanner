# 갭 우선순위 보고서

## P0 — 출시 전 반드시

1. 공급자 한 곳 이상 계약·키·쿼터·허용 용도 확인.
2. 두 번째 공급자를 shadow 비교용으로 연결하거나, 한 곳만으로 출시할 경우 “단일 공급자”를 전면 고지.
3. HotelOfferV1 정규화, 세금/수수료 원장, 가격시각, 판매처 원문 URL을 저장.
4. 검색 API timeout·retry·circuit-breaker와 공급자 장애 배너를 구현.
5. 제휴 deep link와 클릭아웃 실패 복귀를 검증.
6. 제휴·쿠키·수익 고지와 개인정보 보존/삭제를 법률 검토.

## P1 — 상용화 1년차 수준을 만드는 항목

지도/거리, 저장 검색·가격 알림, 리뷰 출처, 지역화, 운영 SLO·온콜, 사용자 신고, 유연한 날짜, 실사용 접근성/Android 회귀를 순서대로 추가한다.

## P2 — 후속 차별화

설명 가능한 추천, 개인화 회원가, 여행 가이드, 가격 예측은 실데이터가 30일 이상 쌓인 뒤 실험한다. 데이터가 없을 때 AI 문구를 최저가 보장처럼 표시하지 않는다.
