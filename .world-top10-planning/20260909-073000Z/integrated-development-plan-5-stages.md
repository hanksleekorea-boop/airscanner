# 통합 5단계 개발계획 v3.2

## 1단계: 공급자·가격 기반

계약/키 확인 → adapter fixture → HotelOfferV1 → 총액·세금·환율 원장 → timeout/429/5xx → `SAMPLE_ONLY`/실시간 분리. 외부 계약 전에는 fixture만 실행한다.

## 2단계: 비교·전환

2개 공급자 병합, 동일 객실 dedupe, 판매처 카드, 허용 deep link, 익명 subId, 클릭아웃 실패 복귀, 제휴·쿠키 고지.

## 3단계: 신뢰·재방문

리뷰 출처, 지도/거리 또는 리스트 fallback, 저장 검색, 가격 알림, 철회·만료, 유연한 날짜, 한국어·원화·영어 정책.

## 4단계: 운영·품질

SLO, 장애 배너, 온콜, 합성 모니터링, 접근성, 성능, 보안, 유휴 Android 한 대의 QR/PWA/오프라인.

## 5단계: 차별화·수익

총액 신뢰지수, 설명 가능한 추천, 회원 혜택, 가격 이력, 승인된 광고·제휴 정산. 직접 결제·예약은 별도 결정 없이는 제외.

각 단계 진입 전 이전 단계의 시험·증거를 확인하고, 외부 차단 시 `BLOCKED_EXTERNAL`로 멈춘 지점을 기록한다.
