# HotelScanner 통합 제품기획 v3.2

## 확정 제품 약속

동일 숙소·객실·날짜·인원 조건의 총액과 취소 조건을 판매처별로 투명하게 비교한다. 공급자 데이터가 없으면 표본을 실시간 가격으로 표시하지 않는다.

## 기존 계획에서 유지

Cloudflare Worker/D1, WeSaver OAuth, PWA, 검색 검증, 총액 원장, 계정 내보내기·삭제, fail-closed 상태, B드라이브/Apple/결제 제외.

## 신규 통합 결정

실시간 공급자 1곳을 P0로 연결하고, 클릭아웃·총액 원장·출처·수집시각을 하나의 사용자 흐름으로 묶는다. 지도·리뷰·알림·지역화는 2~3단계, 신뢰지수·개인화·광고는 실데이터와 법률 승인 뒤에 둔다.

## 전략 원칙

최저가 숫자 하나보다 조건 고정, 세금·수수료 투명성, 공급자 장애 시 안전한 대안, 데이터 최소화를 차별화한다. 경쟁사 화면을 복제하지 않고 결정 원리만 채택한다.

## 성공 지표

가격 필드 완전성 100%, stale 미표시 0건, 허용 외 클릭아웃 0건, 장애 상태 표시 100%, 검색→상세→클릭아웃 성공률·저장 검색 재방문율은 실데이터 확보 후 기준선을 정한다.
