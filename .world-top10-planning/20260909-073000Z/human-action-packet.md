# 사람에게 필요한 한 번의 행동 묶음

## 추천 순서

1. 호텔 공급자 1곳의 제휴 계약, 허용 국가/통화, API 키 발급, 쿼터, 클릭아웃 허용 여부를 공식 문서로 확보한다.
2. 키 원문은 채팅이나 Git에 보내지 말고 Cloudflare Secret에 직접 등록한다.
3. 제휴 수익·쿠키·개인정보·취소 고지를 담당 전문가에게 검토받는다.
4. ADB에 화면이 꺼진 유휴 Android가 나타나면 알려 준다. 그때 한 대만 QR·PWA·오프라인 검증에 사용한다.

## 완료 증거

계약 문서 식별자, Secret 이름(값 제외), 허용 도메인, 법률 승인일, 기기 검증 파일만 공유하면 된다. 비밀번호·OTP·OAuth secret·쿠키는 보내지 않는다.

## 잘못 선택했을 때

공급자 조건이 달라지면 코드를 되돌리지 말고 `WAITING_EXTERNAL`로 유지한 채 계약 조건을 다시 확인한다. 직접 예약·결제 도입은 별도 결정으로 되돌릴 수 없다.
