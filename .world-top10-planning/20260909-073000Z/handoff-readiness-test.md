# 인수인계 준비 테스트

## 개발자 인수 조건

- [ ] `npm test`, typecheck, lint, build, PWA가 통과한다.
- [ ] 공급자 fixture 5종과 API schema 증거가 있다.
- [ ] 환경변수/Secret 이름만 문서화되고 값은 노출되지 않는다.
- [ ] P0 요구사항과 갭 추적 링크가 끊기지 않는다.

## 운영자 인수 조건

- [ ] Cloudflare Worker/D1 배포·롤백 절차가 있다.
- [ ] 공급자 장애·쿼터 초과·stale 가격 대응자가 지정됐다.
- [ ] SLO·온콜·지원 이메일과 개인정보 사고 절차가 있다.

## 공개 전 차단 조건

공급자 계약/키 미확인, 가격 원장 누락, 클릭아웃 고지 미승인, 법률 검토 미완료, 실제 Android 검증이 필요하다고 명시된 릴리스는 `READY_FOR_PUBLIC`로 표시하지 않는다.
