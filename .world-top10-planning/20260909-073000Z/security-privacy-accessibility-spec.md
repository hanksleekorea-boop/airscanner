# 보안·개인정보·접근성 명세

- OAuth state/nonce 검증, 세션 해시, Origin 제한, CSRF·오픈 리다이렉트 차단.
- 개인정보는 목적·보존기간·삭제 방법을 화면에서 한 문장으로 안내한다.
- 클릭아웃·광고 쿠키는 필요한 경우에만 동의 후 사용하며, 제휴 링크임을 표시한다.
- 사용자 데이터 내보내기와 계정 삭제는 재인증/확인 후 즉시 비가역 처리한다.
- WCAG 2.2 AA: 명확한 label, 키보드 순서, 4.5:1 대비, `aria-live` 상태, 44px 터치 영역, reduced motion.
- 스크린리더에서 판매처·총액·환불 조건이 카드 순서대로 읽히고, 지도 없이도 모든 핵심 작업이 가능해야 한다.
