# HotelScanner 서비스 기준선

HotelScanner의 핵심은 “최저가를 주장하는 예약 사이트”가 아니라, 승인된 공급자 가격이 없을 때도 사용자가 숙박 조건을 읽고 비교할 수 있게 하는 표본 의사결정 도구다. 공개판은 Cloudflare와 위세이버 Google 로그인 연결 범위에서는 완성됐지만, 실시간 판매처 가격은 의도적으로 대기 상태다.

핵심 여정은 `유입 → 목적지·날짜·인원 입력 → 조건 검증 → 표본 결과 → 총액·환불·조식 비교 → 비교함·로컬 기록 → 선택적 Google 계정 저장`이다. 실제 예약·결제·제휴 클릭아웃은 현재 실행되지 않는다.

주 비교 범주는 내장 카탈로그 124번 호텔 예약이다. 123번 단기 숙박과 126번 여행 일정은 보조 관찰 범주로만 사용하며 점수에 중복 반영하지 않는다.
